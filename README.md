# Venezuelan-Id-recognition-using-Yolo

This project was made fully on python using yolo, we first detect the id then we get the photo for the profile pic, the name, their number id and birthdate to fill the user data, this was important as we wanted a way for our college security to verify the identity of the person getting into the school. The model was trained with around 200 pics using our own ids in different places to account for bad user pictures, this proved to be the right call as the software presented no issues when tested and we were able to implemented it without problems-
A great success that allowed us to get a remarkable grade in the project and elated our fellow college dental students.
